Фонарик

Фонарик включается через режим TORCH камеры. На некоторых прошивках не поддерживается.

Камера

Показывает все камеры, установленные в системе (включая внешние, если прошивка их видит). Смена камеры перезапускает сенсор — это занимает 1–2 секунды, Live-поток на мгновение прервётся.
Значение -1 = «по умолчанию»: стандартное поведение Android (обычно задняя камера). Выбор сохраняется в конфиге и восстанавливается после перезагрузки.
Смена разрешения камеры (в карточке ниже) тоже требует перезапуска сенсора — оно применится автоматически при сохранении конфига.

Превью с камеры (MJPEG)

Разрешение камеры

«Авто» = самое низкое поддерживаемое разрешение (≥ 128×96) — минимальная нагрузка на CPU. Изменение применяется при следующем запуске камеры (Стоп → Старт).

Контраст

100 = без изменений. 150–200 помогает в сумерках / на низкоконтрастных поверхностях. Для отладки трекера: /api/sensor/debug.jpg.

Ориентация осей

Для сценария «телефон плашмя, камера смотрит вниз»:
вправо = +dx, вперёд = +dy → поворот 0°, инверсия X = off, инверсия Y = on.
Применяется к dx_px, dy_px, distance_px, direction_deg в JSON. Ноль ставится на странице Live, визуализация — на Карте.

Публикация JSON

Изменения меньше порогов — «шум», не публикуются. Первый кадр, изменение фонарика, ручной tare — публикуются всегда.

Стабилизация нуля (калибровка покоя)

Обычно эти поля заполняются автоматически кнопкой «⏱ Калибровать покой + ноль» на странице Live. Ручная правка нужна только для тонкой подстройки.
Если позиция уплывает — уменьшите posDeadbandPx (например, до 0.10) или повторите калибровку. Если медленное движение не улавливается — тоже уменьшите posDeadbandPx.
calibDurationSec — сколько секунд замерять шум покоя. Дольше = точнее (до 60 сек). Минимум 5 сек.

Параметры оптического потока

Изменение этих параметров применяется при следующем запуске камеры (Стоп → Старт).
Поворот: searchRadius ≥ 6 и maxSadPx ≥ 25 нужны, чтобы краевые блоки при вращении попадали в SAD-поиск.

Шумоподавление Optical Flow

Как тюнить: ложные срабатывания в статике → ↑ flowMinVariance / ↑ flowMinGradient; дрожание ±0.3px → ↓ flowTemporalAlpha до 0.4–0.5; «плывёт» на быстрых движениях → ↑ flowTemporalAlpha до 0.8, ↑ searchRadius.
