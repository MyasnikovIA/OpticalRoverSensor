REST API

GET /api/sensor/last — последнее измерение (JSON)
GET /api/sensor/status — статус сервиса и фонарика
GET /api/sensor/sse — поток (Server-Sent Events)
GET /api/sensor/snapshot.jpg — одиночный JPEG-кадр
GET /api/sensor/stream.mjpg — MJPEG-поток
GET /api/sensor/debug.jpg — grayscale-картинка с фичами optical flow
GET /api/sensor/debug.mjpg — grayscale-картинка с фичами optical flow (в движении)
POST /api/sensor/start — запустить трансляцию
POST /api/sensor/stop — остановить трансляцию
POST /api/sensor/zero — установить текущее положение как ноль отсчёта
POST /api/sensor/reset — сбросить накопленную позицию и ноль
POST /api/sensor/flashlight — {"mode":"off|on|auto","threshold":50}
GET / POST /api/sensor/config — настройки (Basic admin/admin)
