# OpticalRoverSensor
# Описание проекта OpticalRoverSensor

**OpticalRoverSensor** — это Android-приложение, превращающее смартфон или планшет в интеллектуальный оптический сенсор (оптическую мышь и компас) для роботов, роверов и других самодельных устройств.

Приложение использует камеру устройства для отслеживания смещения поверхностей (оптический поток), вычисляет пройденное расстояние, направление движения и угол поворота, и передает эти данные по сети в формате JSON.

## Основные возможности

1. **Отслеживание оптического потока (Optical Flow)**
    * Вычисление смещения в пикселях (dx, dy) по видеопотоку с камеры.
    * Использование алгоритма блочного сопоставления (Block Matching / SAD) с субпиксельной интерполяцией.
    * Адаптация под разные углы установки камеры (поворот по осям X, Y).

2. **Встроенный веб-сервер**
    * **HTTP (REST API)**: Получение текущих координат, статуса и настройки.
    * **SSE (Server-Sent Events)**: Потоковая передача JSON-телеметрии в реальном времени (без задержек и опросов).
    * **MJPEG-трансляция**: Просмотр того, что видит камера, а также отладочного вида (`debug.mjpg`) с наложенным вектором движения.
    * **WebSocket и Telnet**: Альтернативные протоколы для обмена данными (управление фонариком, получение координат).

3. **Веб-интерфейс (UI)**
    * Встроенные HTML-страницы (адаптивные под мобильные устройства).
    * **Live-страница**: Калибровка (обнуление координат, настройка шумов), просмотр текущих координат и MJPEG-потока.
    * **Карта (`map.html`)**: Визуализация пути ровера в реальном времени, отрисовка следа и текущего положения.
    * **Настройки (`config.html`)**: Тонкая настройка камеры, порогов срабатывания, фонарика и сетевых интерфейсов.

4. **Калибровка**
    * Автоматическая калибровка "покоя" (определение уровня шума камеры для отсечения ложных срабатываний).
    * Ручная калибровка поворота (привязка смещения кадра к реальному углу поворота устройства).
    * Установка "нуля" (сброс текущих координат в 0,0).

5. **Управление фонариком**
    * Режимы OFF / ON / AUTO (включение по датчику освещенности).

## Архитектура и компоненты

* **`SensorService.java`** — центральный foreground-сервис (работает в фоне). Управляет камерой, координирует работу серверов и обрабатывает кадры в отдельном потоке.
* **`OpticalFlowTracker.java`** — ядро сенсора. Анализирует Y-плоскость (яркость) кадров, находит характерные признаки, вычисляет их смещение и отсекает выбросы.
* **`HttpApiServer.java`, `WebSocketServer.java`, `TelnetServer.java`** — кастомные реализации сетевых серверов, написанные на чистом Java (адаптированные для работы на Android без сторонних тяжелых библиотек).
* **`MainActivity.java`** — обертка для WebView. Автоматически поднимает сервис и открывает локальный веб-интерфейс.
* **`assets/www/`** — веб-клиент (HTML + JS + CSS).

## Принцип работы

1. Камера смартфона непрерывно получает кадры (NV21).
2. Трекер сравнивает текущий кадр с предыдущим, вычисляет медианное смещение `dx` и `dy`.
3. В зависимости от настроек монтажа (`cameraMountRotationDeg`), оси переназначаются.
    * Например, движение вперед может кодироваться как отрицательный `dx` (если камера повернута на 90°).
4. Накопленные значения преобразуются в мировые координаты (X, Y) и угол поворота с учетом текущего курса.
5. Данные отправляются всем подключенным клиентам (в браузер, на пульт управления или в микроконтроллер робота).

## Стек технологий
* **Платформа**: Android (Java), совместимость начиная с Android 4.4 (API 19).
* **Камера**: Legacy Camera API (универсально для старых и новых устройств).
* **Фронтенд**: Ванильный HTML5, CSS3, JavaScript (Canvas API для карты, EventSource для SSE).
* **Сеть**: TCP/IP, HTTP/1.1, Server-Sent Events, WebSocket.

## Применение
Проект идеально подходит для использования в робототехнике, где требуется точное позиционирование (одометрия) без использования энкодеров на колесах. Смартфон закрепляется на днище робота камерой вниз, и система с высокой точностью считает пройденный путь (вперед/назад) и повороты, отправляя телеметрию на центральный компьютер или управляющий контроллер (Arduino, ESP32) по Wi-Fi.
